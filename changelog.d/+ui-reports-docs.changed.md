Documented UI API and Reports API behaviour seen in a real org: an unknown object on `sf.ui.object_info()` raises `Forbidden` (403), not `InvalidType`; `sf.reports.dashboards.refresh()` returns only `statusUrl` and is refused with `Conflict` (409) while a refresh runs and `Forbidden` (403) within a minute of the last one; an unknown dashboard raises `InvalidReference`; a dashboard component has `reportResult: None` until the first refresh.
