Core review fixes: an `{"error": ...}` body outside `/services/oauth2/` (e.g. from an Apex REST class) is classified by status, not as `OAuthError`/`SessionExpired`; `ApexError.body` holds the response body; `sobject` on query events and `NotFound`/`MultipleMatches` names the outer object for queries with subqueries; describe results are private copies (mutating one no longer poisons the cache) and concurrent cache misses fetch once; `sf.auth` events for another `token_key` carry that key's hash; `httpx.DecodingError` and `TooManyRedirects` raise `TransportError`.

Follow-up from review: describe single-flight locks are dropped once idle, so many identities no longer grow memory; `request()` decides text vs bytes from the parsed media type (`+json`/`+xml` suffixes, `text/*`, a `charset`), not substrings; the default HTTP client connects to plain-`http://` loopback hosts directly, so an `HTTP_PROXY` never sees a bearer token in cleartext.
