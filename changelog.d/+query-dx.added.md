SOQL methods take values directly: `sf.query("SELECT Id FROM Lead WHERE Email = {}", email)` on `query`, `query_iter`, `count`, `query_one`, `query_first` and `explain`, quoted by the same code as `esf.soql`. New `sf.query_one()` (exactly one row: `NotFound` / `MultipleMatches`), `sf.query_first()` (first row or `None`), `sf.explain()` (query plans as `QueryPlan`, Salesforce Beta) and `esf.flatten(row)` (dotted lookup keys, flattened child rows) for CSV/DataFrame export; the CLI CSV output uses it.
