Org automation: `sf.actions.standard()`, `flow()` and `apex()` run invocable actions with one input or a list, and `list()` and `describe()` read them. `sf.apex.get/post/put/patch/delete()` call Apex REST classes and raise `ApexError` with the decoded body. `esf generate actions` writes typed stubs (dataclasses, or Pydantic models with `--pydantic`) that you run with `sf.run()`. `FakeSalesforce` gains `on_action()`, `set_action_describe()` and `on_apex()`.
