# even-simpler-salesforce

A modern Salesforce client for Python: async-first with a sync twin, OAuth refresh that
covers every call, typed errors, canonical logs and full coverage of the modern Salesforce APIs.

> **Status: under active development.** This 0.0.1 release is a placeholder; the first usable
> release is 0.1. Follow progress at https://github.com/Uttsavv/even-simpler-salesforce.
